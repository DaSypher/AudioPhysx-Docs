# Blueprint integration

AudioPhysx provides functions and components for connecting game-world information to audio. These features operate outside the MetaSound audio-render loop.

## Start here

- [Flyby integration](flyby.md) — calculate/schedule sounds from projectile paths.
- [Physical playback helpers](playback-helpers.md) — play sounds and register audio components.
- [Acoustic path queries](acoustic-paths.md) — query path information from world geometry.
- [Acoustic components](components.md) — emitter, barrier, portal and bridge concepts.
- [Acoustic materials and settings](materials-and-settings.md) — project-wide acoustic configuration.
