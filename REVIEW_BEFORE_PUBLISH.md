# Documentation review checklist — before Fab release

- [ ] Check every node page against the **final shipping `.cpp`** and a real MetaSound node screenshot.
- [ ] Confirm Blueprint parameter names, including flyby MetaSound external input names, from the final code.
- [ ] Verify at least one example per major feature in standalone and packaged Development.
- [ ] Verify packaging in a clean UE project and Shipping build; record tested platform and engine versions.
- [ ] Replace 'development source' banners and update compatibility and changelog for the actual Fab release.
- [ ] Add support/contact method only when you can maintain it; don't invent emails or Discord invitations.
- [ ] Check all sound recordings in demos have distribution rights.
- [ ] Add genuine, unedited-in-substance UE node and Blueprint screenshots. Cropping/highlighting is fine.
- [ ] Recheck correct playback completion and stop/release semantics for all sample players.
- [ ] Check Sound Cue page remains labelled planned until actual code ships.
- [ ] Rebuild public docs with GitHub Actions, verify navigation, links and mobile layout.
- [ ] Include docs URL on Fab listing.
