# Development and documentation history

**Stereo documentation revision — 27 November 2026.** The site now describes 24 current native MetaSound nodes, including the new `AP: Stereo to Mono` converter. References use the updated `In Left`, `In Right`, `Out Left` and `Out Right` audio paths where present. The prose has been rewritten to explain behaviour, game-audio applications and practical limitations in full paragraphs rather than relying on repetitive tables or isolated pin labels. An accompanying visual stylesheet reduces oversized headings and adds restrained AudioPhysx blue/teal accents.

**Previous playback development.** The plugin source includes a shared Wave Player backend adapter, specialized selection and sequencing players, material-aware playback, projectile flybys and acoustic routing helpers. Start Loop End includes RPM-based scheduling as well as its older completion-based middle mode.

This entry records the source and documentation basis. It is **not** a claim that a Fab v1.0 package has been submitted, validated for Shipping or released. When a commercial package exists, it should receive an explicit version number, release date, supported-engine matrix and meaningful change notes based on that actual binary/source archive.
