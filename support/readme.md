# Support, compatibility and updates

Most AudioPhysx issues fall into three groups: a node was not installed or registered correctly; a playback graph has missing triggers or Wave Assets; or a world-driven node receives data in the wrong units or order.

Start with the [Troubleshooting guide](troubleshooting.md). It separates basic audio problems from build and packaged-game issues, so you can diagnose the smallest possible part of the system.

## Reporting a problem

A useful report says what Unreal Engine and plugin version you're using, how to reproduce the sound or compile issue, and what you expected to happen. Include the **first meaningful compiler error** or a small screenshot of the relevant MetaSound connections rather than only the final error message.
