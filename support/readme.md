# Help and support

- [Troubleshooting](troubleshooting.md) — the fastest checks for common problems.
- [FAQ](faq.md) — design and integration questions.
- [Compatibility](compatibility.md) — verified and unverified engine/platform support.
- [Changelog](changelog.md) — document releases without promising future compatibility.

For problems with a node, capture: Unreal version, plugin version, exact node, log message, MetaSound graph screenshot and reproduction steps. This is much faster to diagnose than a screenshot of a final symptom alone.
