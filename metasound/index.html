MetaSound node library

AudioPhysx extends MetaSounds with native C++ nodes for playing, processing and controlling sound. Choosing the right category is easier when you begin with the question you want your audio to answer.

I want to play recordings more intelligently

Do you need a random variation? A guaranteed order? Multiple simultaneous layers? A start/hold/end action? Explore Playback, which contains the integrated Wave Players.

Playback

Variations, sequences, layers, distance bands, physical materials, gunfire and flybys.

I want the room or material to change the sound

You may need a filter, transmission model, directivity effect or reflection taps rather than another recording. Those tools are under Acoustics.

Acoustics

Obstruction, selected routes, impact shaping, reflections and orientation.

I want motion and travel time to matter

When a source moves or becomes more distant, sound arrival and spectral balance can change. Propagation contains distance delay, Doppler-style control and atmospheric absorption.

Propagation

Timing, Doppler ratios, moving-source delay and air absorption.

I want simpler trigger and control logic

Use QoL for routing triggers, smoothing values and managing trigger repetition. These nodes generally do not decode Wave Assets.

QoL

Distance branching, float smoothing, probability and cooldowns.

How to read a node page

Every reference starts with what happens, then shows a game-audio use case and wiring steps. The exact pin list is folded away under Full input reference / Full output reference so you can still look up types without interrupting the explanation.
