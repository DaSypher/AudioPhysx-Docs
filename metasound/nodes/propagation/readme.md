# Propagation node reference

- [AP: Atmosphere Absorption](atmosphere-absorption.md) — Change high-frequency absorption based on travel distance and air conditions.
- [AP: Distance Delay](distance-delay.md) — Delay mono audio based on distance divided by speed of sound.
- [AP: Dynamic Propagation](dynamic-propagation.md) — Continuously vary sound travel time with source-listener distance, including a bounded Doppler-style effect.
- [AP: Doppler Ratio](doppler-ratio.md) — Compute a pitch ratio from radial source and listener velocities.
