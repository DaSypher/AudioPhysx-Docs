# Visual and editorial decisions

The site uses Retype Free with one lightweight, inline `_includes/head.html` stylesheet. That works without relying on the user's project-specific GitHub Pages URL, premium theme settings or custom hosted font files. The main changes are smaller headings, more paragraph spacing, restrained blue/teal accents, softer callouts, cleaner code and image borders.

The page structure intentionally uses **one H1 and two H2s** on most node pages, with several full explanatory paragraphs in each section. Exact pin references remain accessible inside one collapsible reference block rather than being repeated as large tables. The right-hand table of contents consequently contains fewer large items.

The 24 detailed references remain in their original `docs/metasound/nodes/{category}/` URL structure to preserve prior deep links. Their `nodes` directory is marked hidden in sidebar navigation because the category overviews provide the relevant entry points and the previous site had redundant `Nodes → ... node reference` nesting. The hidden directory does not change the document links in the category guides.

No public PDF, plugin C++ source or stock screenshot has been inserted into this website package. Users add real screenshots later. This is documentation grounded in the uploaded Source.zip, not an Unreal Build Tool compilation or listening test.
