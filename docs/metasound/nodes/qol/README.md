# QoL node reference

- [AP: Distance Switch (Dynamic)](distance-switch.md) — Route a trigger to one of several expandable distance bands.
- [AP: Float Smoother](float-smoother.md) — Apply independent rise and fall smoothing to a floating-point control value.
- [AP: Trigger Cooldown](trigger-cooldown.md) — Let triggers through only when a configured cooldown has elapsed.
- [AP: Trigger Probability](trigger-probability.md) — Allow or reject incoming triggers according to a configurable probability.
