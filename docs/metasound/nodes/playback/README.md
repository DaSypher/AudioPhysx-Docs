# Playback node reference

- [AP: Sequence Wave Player](sequence-wave-player.md) — Play a set of recordings in a fixed order, starting each wave after the previous one finishes.
- [AP: Random Sequence Wave Player](random-sequence-wave-player.md) — Play an ordered sequence where each step chooses one random recording from an array.
- [AP: Start Loop End Player](start-loop-end.md) — Play a randomized introduction, repeat middle recordings, then play a randomized ending on release.
- [AP: Random Wave Player](random-wave-player.md) — Select one random playable Wave Asset and output its mono audio.
- [AP: Shuffle-Bag Wave Player](shuffle-bag-wave-player.md) — Draw from a weighted bag of wave variations while reducing repetition across successive triggers.
- [AP: Layered Wave Player](layered-wave-player.md) — Trigger multiple Wave Assets as a single sound stack, with per-layer gain, pitch and onset delay.
- [AP: Distance Wave Player](distance-wave-player.md) — Choose recordings from configurable distance ranges at play time.
- [AP: PhysMat Wave Player](physmat-wave-player.md) — Select recordings by exact Physical Material asset path, with fallback recordings.
- [AP: Surface Wave Player](surface-wave-player.md) — Select waves using Unreal physical surface types and a configured route table.
- [AP: Flyby Wave Player](flyby-wave-player.md) — Play randomized near-miss whizz recordings, optionally including a ballistic crack layer.
